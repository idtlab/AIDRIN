Unit Metadata Audit and Repair

Audit every variable and resolve missing or incorrect unit metadata. Units are stored in a separate JSON file; the source dataset is never modified.

Auditing existing unit metadata...

For each variable needing review, choose Has a physical unit, then select a suggested unit. Suggestions are based on the variable name; unrecognized names show the full common-unit list. If you need to type a unit, use a Pint-compatible spelling; dataset-specific units unknown to Pint are flagged as unrecognized. Choose Dimensionless for unitless quantities, or choose No unit applies for identifiers, timestamps, labels, and free text.

Columns that identify each series

Rows with the same values in these columns form one series. For example, select station and channel to check each station–channel pair separately.

Units depend on time format

For numeric time, use the column’s units. For dates and times, use seconds. In seconds, enter 0.01 for samples 10 milliseconds apart.

Define Custom Metric

How to use this panel

  1. Write a metric() method below that returns a dictionary of results based on your own criteria.
  2. Optionally, write a remedy() method that returns a cleaned or corrected version of the dataset. It must return a pandas DataFrame. Any other return type will fail. Leave it as-is if you don't need it.
  3. Click Save any time you change the code. Submit always runs the last saved version, not whatever is currently typed in the editor.
  4. If you want to download the remedied dataset, check the Apply Remedy box below before clicking Submit. If it is left unchecked, remedy() will not run and no download link will appear, even if you wrote one.
  5. Click Submit to run your code against the currently uploaded dataset.
  6. Metric results appear below. If Apply Remedy was checked, a download link for the remedied dataset is included with the results (always a CSV file, regardless of the original format).

This box must be checked before you click Submit to generate a downloadable remedied dataset — it is unchecked by default on every run, even after a previous run. It is always saved as a CSV file, regardless of the original file's format.

Custom metrics and remedied data are stored for 1 hour.
